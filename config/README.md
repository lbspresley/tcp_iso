# 부산은행 BOK 서비스 구성
- BOKA : 차세대 신한국은행망 실시간
- BOKB : 차세대 신한국은행망 일괄
    - BOKB_S : 일괄 송신
    - BOKB_R : 일괄 수신
- BOKC : 차세대 국고 실시간
- BOKD : 차세대 국고 일괄
    - BOKD_S : 일괄 송신
    - BOKD_R : 일괄 수신

## 기존 서비스 구성(미사용)
- BOK1 : 한국은행망 TCP/IP 일괄
    - BOK1_S : 일괄 송신
    - BOK1_R : 일괄 수신
- BOK2 : 신한국은행망 TCP/IP 일괄
    - BOK2_S : 일괄 송신
    - BOK2_R : 일괄 수신
