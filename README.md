## 2. 작업 순서

1. 설치 파일 준비
- 어뎁터 소스 및 binary : tcp_iso/ 
- 서비스 환경 
    - $ROME_HOME/config/upconfig/oal2.ini
    - tpcfg.m : SERVER-oal2, SERVICE-OAL2
    - 전문라우팅 정보 : 코어 <--> OAL2
2. 소스 빌드
```bash
$ cd tcp_iso
$ make install
```

3. 환경 구성
- oal2.ini : 암호화키 정보 확인 및 설정
- tpcfg.m : 한은ISO용 서비스 정보 등록(OAL2)
- OAL1 : 기존 한은망 어뎁터에서 개시전문 전달 내용 수정 대응

4. 어뎁터 기동
- tpcfg.m 수정내용 확인 및 빌드
```bash
# config build
$ mcfg

# 수정된 config 실시간 적용
$ spcom -crecfg
``` 
- 어뎁터 기동 
```bash
$ upcom -c start -n oal2
```

- 어뎁터 로그 및 트레이스 확인
```bash
# view log
$ vlog -n oal2

# view trace
$ vtrc -n oal2
```
